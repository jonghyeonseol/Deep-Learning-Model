utils.modern_trainer module

Modern training utilities with state-of-the-art techniques.

This module implements: - AdamW optimizer (decoupled weight decay) - Cosine annealing with warmup - Mixed precision training (AMP) - Gradient clipping and accumulation - Label smoothing - EMA (Exponential Moving Average)

class utils.modern_trainer.LabelSmoothingCrossEntropy(smoothing=0.1)[source]

Bases: Module

Label Smoothing Cross Entropy Loss.

Prevents the model from becoming over-confident by distributing some probability mass to incorrect classes.

Instead of targets [0, 0, 1, 0] (one-hot), use smoothed targets [0.03, 0.03, 0.91, 0.03] (with smoothing=0.1)

Parameters:

smoothing – Label smoothing factor (0.0 to 1.0, typically 0.1)

class utils.modern_trainer.CosineAnnealingWarmupRestarts(optimizer, first_cycle_steps=200, warmup_steps=50, max_lr=0.001, min_lr=1e-05, gamma=1.0)[source]

Bases: _LRScheduler

Cosine Annealing with Warm Restarts and Linear Warmup.

Combines: 1. Linear warmup: Gradually increases LR from 0 to max_lr 2. Cosine annealing: Smoothly decreases LR following cosine curve 3. Warm restarts: Periodically resets LR to restart training

Parameters:

  • optimizer – Wrapped optimizer

  • first_cycle_steps – Number of steps in first cycle

  • warmup_steps – Number of warmup steps

  • max_lr – Maximum learning rate

  • min_lr – Minimum learning rate

  • gamma – Decay factor for cycle length after restart

Modern trainer with state-of-the-art training techniques.

Features: - AdamW optimizer with decoupled weight decay - Cosine annealing with warmup - Automatic Mixed Precision (AMP) for 2-3x speedup - Gradient clipping for stability - Gradient accumulation for large batch simulation - Label smoothing for better calibration - EMA for improved generalization - TensorBoard logging

Parameters:

  • model – Neural network model

  • train_loader – Training data loader

  • val_loader – Validation data loader

  • test_loader – Test data loader

  • device – Device to train on

  • save_dir – Directory for checkpoints
